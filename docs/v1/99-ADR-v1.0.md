**Document** : ADR Index

**Version** : 1.0

**Statut** : Active

---

# Objectif

Les ADR (Architecture Decision Records) documentent les décisions structurantes prises au cours du projet.

Une ADR n'est jamais modifiée de manière rétroactive.

Si une décision évolue, une nouvelle ADR est créée.

# Cycle de vie

Une ADR possède un des statuts suivants :

- Draft
- Accepted
- Deprecated
- Superseded

---

# Règles

Les ADR complètent les TSPEC.

Les TSPEC décrivent **comment construire**.

Les ADR expliquent **pourquoi les décisions ont été prises**.
