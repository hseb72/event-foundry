# Go-To-Market Strategy

**Document** : STRAT.03

**Fichier** : 10-STRAT.03-GoToMarket-v1.0.md

---

# Objectif

Définir la stratégie de lancement et d'adoption d'EventFoundry.

Ce document décrit les hypothèses permettant d'atteindre une masse critique d'utilisateurs et d'organisateurs afin de créer un effet réseau durable.

Il ne traite pas des aspects techniques mais de la stratégie de diffusion du produit.

---

# Le défi principal

EventFoundry est une plateforme bi-face.

Elle met en relation :

- des organisateurs ;
- des consommateurs.

Ces deux populations dépendent l'une de l'autre.

Les consommateurs souhaitent consulter un catalogue riche.

Les organisateurs souhaitent publier sur une plateforme possédant déjà une audience.

Ce phénomène est connu sous le nom de :

> **Chicken and Egg Problem**

La stratégie de lancement doit permettre de casser ce cercle.

---

# Principe directeur

Le lancement ne doit pas chercher à couvrir immédiatement un territoire entier.

Au contraire, il doit viser une zone géographique volontairement limitée.

La densité est plus importante que la couverture.

---

# Première cible

Le premier marché doit être suffisamment petit pour être maîtrisé.

Exemples :

- une ville moyenne ;
- une agglomération ;
- une communauté de communes.

Une fois la masse critique atteinte, la plateforme pourra être étendue progressivement.

---

# Pourquoi une approche locale ?

Les événements sont, par nature, locaux.

Un utilisateur ne cherche généralement pas des événements dans tout le pays.

Il cherche :

- ce qui se passe près de chez lui ;
- ce soir ;
- ce week-end.

La proximité est donc un facteur essentiel d'adoption.

---

# Première phase

## Construire le catalogue

Le premier objectif n'est pas d'acquérir des consommateurs.

Le premier objectif est de constituer un catalogue suffisamment attractif.

Cette phase repose principalement sur les organisateurs.

---

## Identifier les premiers partenaires

Les premiers partenaires doivent être faciles à convaincre.

Exemples :

- associations ;
- médiathèques ;
- musées ;
- galeries ;
- mairies ;
- maisons de quartier ;
- salles municipales.

Ces acteurs disposent généralement d'une programmation régulière.

---

## Réduire l'effort de publication

L'import OCR constitue un argument différenciant.

L'organisateur peut importer :

- une affiche ;
- un flyer ;
- un programme PDF.

La création d'un événement devient beaucoup plus rapide que sur les plateformes concurrentes.

---

# Deuxième phase

## Attirer les consommateurs

Lorsque le catalogue devient suffisamment riche, la communication peut commencer.

Les premiers utilisateurs doivent percevoir immédiatement la valeur de la plateforme.

Ils doivent trouver :

- plusieurs événements chaque semaine ;
- plusieurs organisateurs ;
- des recommandations pertinentes.

Une plateforme vide ne fidélise pas.

---

## Les suivis

Les suivis jouent un rôle majeur dans la fidélisation.

L'utilisateur suit :

- des organisateurs ;
- des lieux ;
- des activités.

Le contenu vient ensuite naturellement vers lui.

La plateforme devient un compagnon plutôt qu'un moteur de recherche.

---

## Le planning personnel

Le planning constitue l'écran principal.

Il encourage les visites régulières.

Même lorsqu'aucune recherche n'est effectuée.

---

# Troisième phase

## Développer les organisateurs

Une fois les premiers consommateurs présents, les organisateurs bénéficient d'une visibilité réelle.

Le bouche-à-oreille peut alors fonctionner.

Les nouveaux organisateurs rejoignent la plateforme pour toucher cette audience.

L'effet réseau commence à apparaître.

---

# Quatrième phase

## Monétiser progressivement

La monétisation intervient uniquement après la création de valeur.

Les premières offres payantes concernent :

- statistiques ;
- outils avancés ;
- API ;
- automatisations.

Les fonctionnalités essentielles restent gratuites.

---

# Proposition de valeur

## Pour les organisateurs

Avant EventFoundry :

- saisie répétitive ;
- multiples plateformes ;
- perte de temps.

Avec EventFoundry :

- import d'un document existant ;
- correction éventuelle ;
- publication.

Le gain de temps constitue l'argument principal.

---

## Pour les consommateurs

Avant EventFoundry :

- plusieurs agendas ;
- plusieurs réseaux sociaux ;
- plusieurs sites web.

Avec EventFoundry :

- un planning unique ;
- une découverte personnalisée ;
- des recommandations locales.

---

# Les facteurs différenciants

La communication ne doit pas insister sur la technologie.

Les utilisateurs ne recherchent pas un moteur OCR.

Ils recherchent un bénéfice.

Les messages doivent rester simples.

Exemples :

- Découvrez tout ce qui se passe autour de vous.
- Organisez facilement vos sorties.
- Ne manquez plus les événements des lieux que vous aimez.
- Publiez vos événements en quelques minutes.

La technologie constitue un moyen.

Jamais un argument commercial principal.

---

# Les premiers canaux d'acquisition

## Organisateurs

Approche directe.

Exemples :

- email ;
- téléphone ;
- rencontres locales ;
- salons associatifs ;
- offices de tourisme.

---

## Consommateurs

Communication locale.

Exemples :

- réseaux sociaux ;
- presse locale ;
- newsletters ;
- partenariats avec les organisateurs.

Les organisateurs deviennent eux-mêmes des ambassadeurs.

---

# Les collectivités

Les collectivités représentent un accélérateur.

Lorsqu'une ville adopte la plateforme, elle peut :

- promouvoir son utilisation ;
- encourager les associations ;
- référencer les événements municipaux.

L'effet de levier est important.

---

# Les indicateurs de succès

Le suivi de la croissance repose sur quelques indicateurs simples.

## Catalogue

- nombre d'événements publiés ;
- nombre d'organisateurs actifs ;
- événements par semaine.

---

## Consommateurs

- utilisateurs actifs mensuels ;
- consultations ;
- événements enregistrés ;
- suivis créés.

---

## Engagement

- réservations ;
- taux de retour ;
- fréquence des visites ;
- notifications ouvertes.

---

## Organisateurs

- fréquence de publication ;
- taux d'utilisation de l'OCR ;
- délai moyen de publication.

---

# Ce qu'il faut éviter

## Croissance géographique trop rapide

Une plateforme peu dense dans plusieurs villes apporte moins de valeur qu'une plateforme très riche dans une seule.

---

## Fonctionnalités prématurées

Chaque nouvelle fonctionnalité doit répondre à un besoin clairement identifié.

La simplicité reste un avantage concurrentiel.

---

## Monétisation trop précoce

La priorité est de construire :

- une audience ;
- un catalogue ;
- une réputation.

La monétisation intervient ensuite.

---

# Vision à moyen terme

Une fois la plateforme installée dans plusieurs territoires, EventFoundry peut devenir :

- la référence locale de découverte d'événements ;
- la plateforme privilégiée des organisateurs ;
- le partenaire numérique des collectivités.

Le moteur de structuration de données permet alors d'alimenter d'autres services numériques.

---

# Les effets réseau

Le développement d'EventFoundry repose sur un cercle vertueux.

```text
Plus d'organisateurs
        │
        ▼
Plus d'événements
        │
        ▼
Catalogue plus riche
        │
        ▼
Plus de consommateurs
        │
        ▼
Plus de visibilité
        │
        ▼
Plus d'organisateurs
```

Chaque nouvelle boucle renforce la valeur de la plateforme.

---

# Une ambition réaliste

L'objectif n'est pas de devenir immédiatement une plateforme nationale.

L'objectif est de devenir indispensable localement.

Une fois cette position atteinte sur un territoire, son extension vers d'autres villes devient beaucoup plus simple.

La croissance repose sur la répétition d'un modèle éprouvé plutôt que sur une expansion rapide.

---

# Conclusion

Le succès d'EventFoundry dépend davantage de son adoption que de sa richesse fonctionnelle.

La stratégie privilégie :

- une implantation locale forte ;
- une expérience remarquable pour les organisateurs ;
- une expérience personnalisée pour les consommateurs ;
- une croissance progressive fondée sur les effets réseau.

La technologie constitue un avantage concurrentiel important, mais c'est la simplicité d'usage et la qualité de l'écosystème qui assureront durablement le développement de la plateforme.
