# Objectif

Définir les hypothèses de création de valeur et les modèles économiques envisagés pour EventFoundry.

Ce document ne constitue pas un business plan détaillé. Il décrit les orientations stratégiques retenues afin d'assurer la pérennité économique de la plateforme tout en restant cohérent avec sa vision produit.

---

# Philosophie

Le modèle économique d'EventFoundry repose sur un principe simple :

> Les consommateurs créent la valeur d'usage.
>
> Les organisateurs créent le contenu.
>
> La plateforme crée la rencontre entre les deux.

Le financement de la plateforme ne doit jamais dégrader l'expérience utilisateur.

---

# Les parties prenantes

L'écosystème repose sur quatre acteurs principaux.

## Les consommateurs

Ils utilisent gratuitement la plateforme pour :

- découvrir des événements ;
- organiser leurs sorties ;
- suivre leurs organisateurs favoris ;
- suivre des lieux ;
- recevoir des recommandations.

Ils constituent la principale source d'audience.

---

## Les organisateurs

Ils publient leurs événements.

Ils enrichissent continuellement le catalogue.

Ils représentent la première cible commerciale.

---

## Les collectivités

Les collectivités cherchent à promouvoir la vie locale.

Exemples :

- communes ;
- communautés de communes ;
- métropoles ;
- départements ;
- régions ;
- offices de tourisme.

Elles représentent une cible B2G (Business to Government).

---

## Les lieux

Certains lieux disposent d'une programmation régulière.

Exemples :

- musées ;
- galeries d'art ;
- salles de spectacles ;
- médiathèques ;
- commerces ;
- centres commerciaux.

Ils peuvent disposer de besoins spécifiques de communication et de valorisation.

---

# Ce qui crée de la valeur

La plateforme crée de la valeur grâce à plusieurs mécanismes.

## Simplification

L'import OCR réduit fortement le temps nécessaire à la création d'un événement.

Une information déjà présente sur une affiche ou un programme est réutilisée automatiquement.

---

## Structuration

Les données deviennent homogènes.

Tous les événements possèdent :

- des dates ;
- un lieu ;
- une activité ;
- un organisateur ;
- une classification cohérente.

Cette qualité constitue un actif stratégique.

---

## Visibilité

Les organisateurs bénéficient d'une meilleure visibilité.

Les consommateurs découvrent davantage d'événements pertinents.

La plateforme crée un cercle vertueux.

---

## Personnalisation

Le système de recommandations repose sur :

- les suivis ;
- les centres d'intérêt ;
- les participations ;
- la proximité.

Chaque utilisateur bénéficie d'une expérience adaptée à ses préférences.

---

# Principes économiques

Plusieurs principes guident le choix du modèle économique.

## Le consommateur n'est pas le client

Le consommateur est l'utilisateur final.

Il constitue la principale richesse de la plateforme.

L'objectif est de supprimer les freins à son adoption.

---

## Les organisateurs financent des services

Les fonctionnalités essentielles restent accessibles gratuitement.

Les services professionnels deviennent payants lorsqu'ils apportent une réelle valeur métier.

---

## Les données personnelles ne sont pas un produit

Les données personnelles ne sont jamais revendues.

La confiance constitue un avantage concurrentiel durable.

---

# Offres destinées aux consommateurs

## Offre gratuite

Le consommateur bénéficie gratuitement de l'ensemble des fonctionnalités principales.

Exemples :

- découverte ;
- recherche ;
- planning personnel ;
- suivis ;
- réservations ;
- notifications ;
- favoris.

L'objectif est de maximiser l'adoption.

---

## Abonnement Premium

À ce stade, aucun abonnement Premium destiné aux consommateurs n'est prévu.

Cette possibilité reste ouverte pour des fonctionnalités futures mais ne constitue pas une priorité stratégique.

---

# Offres destinées aux organisateurs

## Offre Gratuite

L'offre gratuite doit permettre une utilisation réelle de la plateforme.

Elle comprend notamment :

- création d'événements ;
- import OCR ;
- gestion du catalogue ;
- page organisateur ;
- publication.

Cette offre constitue le moteur de croissance de la plateforme.

---

## Offre Pro

L'offre Pro s'adresse aux structures publiant régulièrement des événements.

Fonctionnalités possibles :

- statistiques avancées ;
- indicateurs de fréquentation ;
- taux d'intérêt ;
- réservations ;
- exports ;
- personnalisation ;
- gestion de plusieurs collaborateurs.

Le modèle privilégié est un abonnement mensuel.

---

## Offre Premium

Cette offre cible les organisations disposant de besoins d'intégration.

Exemples :

- API ;
- synchronisation automatique ;
- widgets ;
- import automatisé ;
- intégrations avec des outils tiers.

---

# Offres destinées aux collectivités

Les collectivités peuvent disposer d'une plateforme personnalisée.

Exemples :

- portail territorial ;
- identité graphique ;
- statistiques locales ;
- administration dédiée ;
- tableaux de bord.

Le modèle économique est une licence SaaS.

---

# Offres destinées aux lieux

Les lieux accueillant régulièrement des événements peuvent bénéficier d'outils spécifiques.

Exemples :

- page enrichie ;
- calendrier intégré ;
- QR Codes ;
- widgets ;
- statistiques ;
- écrans d'affichage.

---

# Partenariats

EventFoundry n'a pas vocation à remplacer les plateformes spécialisées.

Des partenariats peuvent être développés avec :

- solutions de billetterie ;
- plateformes associatives ;
- outils CRM ;
- sites institutionnels.

La plateforme devient un point d'entrée vers ces services.

---

# Ce qui n'est pas envisagé

## Publicité intrusive

La plateforme ne repose pas sur un modèle publicitaire.

L'expérience utilisateur reste prioritaire.

---

## Billetterie propriétaire

La vente de billets constitue un métier distinct.

Elle implique :

- paiement ;
- remboursement ;
- obligations réglementaires ;
- support.

EventFoundry privilégie l'intégration de solutions existantes.

---

## Vente de données personnelles

La plateforme ne commercialise jamais les données personnelles de ses utilisateurs.

---

# Valorisation des données

Des données agrégées et anonymisées peuvent être produites.

Exemples :

- évolution de la fréquentation ;
- répartition géographique des événements ;
- tendances saisonnières ;
- catégories d'activités ;
- fréquentation des quartiers.

Ces informations peuvent intéresser :

- collectivités ;
- offices de tourisme ;
- fédérations ;
- partenaires institutionnels.

Le respect du RGPD constitue un prérequis.

---

# Le moteur de structuration

Au-delà de l'application, EventFoundry développe un moteur de structuration de données événementielles.

Pipeline :

Document

↓

OCR

↓

Classification experte

↓

Événement structuré

Cette technologie constitue un actif pouvant alimenter :

- applications mobiles ;
- sites web ;
- agendas territoriaux ;
- bornes interactives ;
- affichages dynamiques ;
- API partenaires.

La plateforme grand public représente une première utilisation de cette technologie.

# Facteurs de réussite

Le succès économique repose sur plusieurs conditions.

- attirer un grand nombre d'organisateurs ;
- proposer une expérience consommateur remarquable ;
- produire une donnée fiable ;
- construire un effet réseau local ;
- développer progressivement les offres professionnelles.

---

# Risques

Plusieurs risques doivent être surveillés.

## Faible masse critique

Sans organisateurs, le catalogue reste limité.

Sans consommateurs, les organisateurs ne voient pas d'intérêt.

La croissance doit donc viser simultanément les deux populations.

---

## Complexité excessive

Les fonctionnalités payantes ne doivent jamais compliquer l'offre gratuite.

La simplicité reste un facteur de différenciation.

---

## Dépendance à un seul modèle économique

La diversification des revenus constitue un objectif.

Les abonnements, licences et partenariats permettent de limiter ce risque.

---

# Vision à long terme

L'objectif n'est pas de devenir une plateforme de billetterie.

L'objectif est de devenir la référence de la donnée événementielle locale.

L'application mobile et le site web constituent les premières vitrines de cette capacité.

À terme, EventFoundry pourra alimenter de nombreux services numériques grâce à une donnée fiable, structurée et constamment mise à jour.

---

# Conclusion

Le modèle économique d'EventFoundry repose sur un équilibre entre une expérience gratuite de grande qualité pour les consommateurs et des services professionnels à forte valeur ajoutée destinés aux organisateurs, aux collectivités et aux lieux.

La création de valeur provient avant tout de la qualité de la donnée événementielle produite par la plateforme, de sa capacité à simplifier le travail des organisateurs et de son aptitude à proposer aux utilisateurs une expérience personnalisée centrée sur leurs envies de sorties.
