# Objectif

Définir les fonctionnalités de découverte d'EventFoundry.

La découverte permet à l'utilisateur d'explorer librement l'offre culturelle disponible.

Elle complète les recommandations proposées par l'assistant culturel.

---

# Philosophie

La découverte répond à une intention explicite.

L'utilisateur souhaite rechercher, explorer ou préparer une activité.

Contrairement au planning, la découverte est initiée par l'utilisateur.

---

# Les objectifs

La découverte permet notamment de :

- rechercher un événement ;
- découvrir une activité ;
- explorer une ville ;
- préparer un séjour ;
- consulter les événements d'un organisateur ;
- explorer un lieu culturel.

---

# Les modes de découverte

La plateforme propose plusieurs modes de découverte.

## Recherche

L'utilisateur formule un besoin précis.

Exemples :

- un concert de jazz ;
- une exposition ;
- un festival.

Les résultats sont filtrables et triables.

---

## Navigation

L'utilisateur explore librement le catalogue.

Il peut parcourir :

- les catégories ;
- les activités ;
- les lieux ;
- les organisateurs.

---

## Pour vous

La rubrique **Pour vous** présente des recommandations personnalisées produites par le moteur de recommandation.

Elle constitue le point d'entrée principal de l'expérience Explorer.

---

## Surprends-moi

Le mode **Surprends-moi** favorise la découverte de nouvelles expériences culturelles.

Il réduit volontairement le poids des habitudes de l'utilisateur afin de proposer des événements plus variés.

---

# Les critères de recherche

La recherche peut être affinée selon différents critères.

Exemples :

- date ;
- période ;
- localisation ;
- distance ;
- activité ;
- organisateur ;
- lieu ;
- accessibilité ;
- gratuit / payant.

Les critères pourront évoluer sans modifier les principes de fonctionnement.

---

# Les résultats

Chaque résultat présente les informations essentielles permettant de prendre une décision.

Notamment :

- titre ;
- date ;
- lieu ;
- organisateur ;
- activité ;
- distance ;
- disponibilité ;
- actions possibles.

---

# Les actions

Depuis un résultat, l'utilisateur peut notamment :

- consulter le détail ;
- ajouter au planning ;
- suivre l'événement ;
- réserver ;
- partager ;
- consulter l'organisateur.

---

# Les interactions

La découverte interagit avec les autres domaines de la plateforme.

Une réservation alimente le planning.

Un suivi améliore les recommandations.

Une participation enrichit le profil culturel de l'utilisateur.

---

# Les principes

## Une recherche rapide

L'utilisateur doit obtenir une réponse pertinente avec un minimum d'effort.

---

## Une découverte ouverte

La plateforme encourage l'exploration sans imposer de parcours.

---

## Une continuité avec le planning

Tout événement découvert peut être intégré facilement au planning.

---

## Une personnalisation maîtrisée

Les recommandations enrichissent la découverte sans masquer le catalogue.

L'utilisateur conserve toujours la possibilité d'explorer librement.

---

# Notre différence

La découverte n'est plus le cœur du produit.

Elle devient un moyen d'enrichir le planning personnel.

Le catalogue reste une ressource au service de l'utilisateur.
