# Objectif

Ce document constitue l'index de référence de la documentation EventFoundry V2.

Il décrit l'organisation documentaire, les documents prévus, leur état d'avancement ainsi que leurs dépendances.

Toute évolution de la documentation doit être répercutée dans cet index.

La documentation V2 conserve la même organisation générale que la documentation V1.

Les documents sont regroupés par domaine documentaire.

Chaque document possède un identifiant unique.

Les numérotations existantes sont conservées afin de préserver la cohérence de l'ensemble documentaire.
